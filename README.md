# Milaan Reisapp 2026

## Zo zie je de echte app
Open `index.html` in een browser. Klik op GitHub niet alleen op het bestand, want GitHub toont dan de broncode als tekst.

## Publiceren via GitHub Pages
1. Upload `index.html` naar de hoofdmap van een nieuwe GitHub-repository.
2. Ga naar **Settings > Pages**.
3. Kies **Deploy from a branch**.
4. Selecteer **main** en **/(root)** en klik **Save**.
5. Open daarna de GitHub Pages-URL, niet de normale repository-URL.

Deze versie bestaat bewust uit één zelfstandig `index.html`-bestand. CSS en JavaScript staan in hetzelfde bestand, zodat er geen map- of padproblemen kunnen ontstaan.
